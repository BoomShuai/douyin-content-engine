# 采集与响应适配的边界

默认工作台只处理用户导入的文件和合成演示，不会自动访问抖音。公开页面检查和已保存响应适配属于可选 SDK / CLI，未完成真实平台评论采集验收。

离线转换合法保存的评论响应：

```sh
python3 -m douyin_engine collector import-response private/comments-response.json --output outputs/adapted.json
```

只接受评论响应 JSON，不接受 HAR、Cookie 或请求头导出。仅读取明确识别的评论数组；昵称、头像、IP 标签和未使用字段不进入规范结果。回复和父评论关系只能来自输入，不能推断缺失边。最多保留响应顺序下的 300 条，元数据披露观察、去重、截断和被跳过的数量。

`collect` 子命令只接受 `https://www.douyin.com/video/数字ID` 格式的明确公开视频 URL。只请求有限 HTML，不执行 JavaScript、不使用浏览器账号、代理、Cookie、签名或登录态，不访问任意主机。最多两次请求，受限、验证码、重定向超出白名单或资源超限即停止，不持续重试。

HTML 可访问不等于评论取得成功；没有评论时不编造记录。源码测试仅使用离线合成夹具，不访问真实平台。本次公开整理也没有执行真实平台抓取。

使用者应确认对输入和采集行为有相应权限；公开页面并不等于可以任意收集、公开或再分发其中的个人数据。本工具不提供突破访问限制的功能。
