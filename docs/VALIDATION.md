# 验证记录

这里验证软件功能、安装和数据边界，不提供真实抖音数据上的准确率结论。

## 软件检查

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
node scripts/test_frontend.cjs
python3 scripts/privacy_check.py --history
```

公开版本定义 156 项 Python 测试：默认执行 148 项，另外 8 项真实模型检查需显式开启。前端有 35 项离线逻辑检查。范围包括输入质量、时间、隐私模式遮盖、观点证据、否定范围、空桶/缺口、回复图、标签不可判定、CSV 公式防护、本机 HTTP 来源、原始机器标签保留、源码打包白名单、清单及篡改校验。

真实模型组在本地使用既有兼容权重和 CPU，阻断 socket 与 DNS，8 项全部通过，验证加载、分数范围、单条/批量一致性、无法判定输入及没有外连尝试。权重未公开，因此公开 CI 不下载模型，也不声称执行这组真实推理。

CI 在 Ubuntu 22.04 / Python 3.9、当前 Ubuntu / Python 3.12、Windows / Python 3.9 和 3.12 上运行软件测试、安装包资源检查、隐私扫描及源码 ZIP 验证。Windows 不假设有符号链接创建权限，相关 symlink 用例在 Unix 环境验证。每次结果以仓库 Actions 页面为准。

## 安装与换目录

默认模式用 `python3 -S` 验证，不依赖第三方 site-packages。独立虚拟环境安装后，在源码目录之外执行 CLI、36 条合成演示和真实回环 HTTP，请求安装包自带网页资源。源码 ZIP 会重新核对全部成员 SHA-256，并解压换目录验证启动和演示。

ZIP 只包含白名单公开源码，不含模型、私人输入、原始语料、历史评测、报告或虚拟环境；即使私人内容误放在允许的源文件中，发布扫描也会按已配置模式拒绝。模式检查不等于完整隐私证明。

## 实际浏览器

完成以下操作：

- 规则模式分析 36 条合成演示，查看总览、时序主题、回复网络和原文证据。
- 记录一条独立人工复核，导出 JSON 与 CSV；文件保留 36 条记录，人工标签未覆盖原始机器标签。
- 导入单独的合成 CSV，导出来源为 `local_import`，不含输入文件名。
- 使用本机已有模型进行 36 条演示推理，并恢复默认规则模式。
- 单条评论分析；HTML 标签样式输入以文本显示，不创建图片元素。
- 公开证据页明确没有历史指标，没有读取旧实验或逐条预测。
